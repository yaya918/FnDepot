# Scrypted

Scrypted是一个高性能家庭视频集成平台和NVR（网络视频录像机），支持HomeKit、Google Home和Alexa。提供实时视频流、智能检测、插件化架构，可将各种摄像头和智能设备集成到统一的智能家居生态中。基于Scrypted开源项目进行打包。（飞牛应用商店已同步上架，版本相同）

## 功能特性

- **智能家居集成**: 支持HomeKit、Google Home和Alexa，实现统一控制
- **实时视频流**: 提供高质量的实时视频流传输
- **智能检测**: 支持运动检测、人脸识别等智能功能
- **插件化架构**: 丰富的插件生态系统，支持多种设备类型
- **NVR功能**: 网络视频录像机功能，支持视频录制和回放
- **多摄像头支持**: 可集成多种品牌和型号的摄像头
- **跨平台兼容**: 支持多种操作系统和设备

## 安装要求

- 系统架构: x86_64
- 运行环境: Linux
- 端口: 10443
- 依赖: python312, nodejs_v22
- 数据路径: `/vol[x]/@appshare/scrypted-data`（路径中不能存在中文）

## 使用方法

1. 安装应用后，通过浏览器访问 `https://<你的NAS IP>:10443`
2. 首次访问时进行初始配置和账户设置
3. 添加摄像头和其他智能设备
4. 配置智能检测和自动化规则
5. 通过Web界面或智能家居平台进行管理

## 配置说明

- **数据存储**: 默认数据保存在 `/vol[x]/@appshare/scrypted-data`
- **设备集成**: 支持ONVIF、RTSP等多种协议的摄像头
- **智能服务**: 可配置AI检测、通知推送等功能
- **用户管理**: 支持多用户和权限管理

## 注意事项

- 确保网络可访问，防火墙开放相应端口
- 数据路径中不能包含中文字符
- 建议使用HTTPS进行安全通信
- 定期更新应用以获取最新功能和安全修复
- 确保有足够的存储空间用于视频录制

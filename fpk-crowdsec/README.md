# CrowdSec 安全防护系统

CrowdSec 是一个开源的、协作式的入侵防御系统（IPS），通过收集和分析来自全球用户的安全威胁情报，为服务器提供实时的安全防护。

## 功能特性

- **威胁检测**: 基于行为分析技术，实时检测网络攻击和恶意行为
- **自动防护**: 检测到威胁后自动封禁攻击源IP
- **全球协作**: 共享威胁情报，共同构建更安全的网络环境
- **轻量级**: 资源占用低，对系统性能影响小
- **易于集成**: 支持与多种防火墙和代理集成

## 使用场景

- Web 服务器防护
- SSH 暴力破解防护
- API 接口防护
- DDoS 攻击缓解
- 恶意爬虫防护

## 安装说明

1. 在 FnDepot 应用源中搜索并安装 CrowdSec
2. 安装后通过 Web 界面进行配置
3. 根据需要配置防护规则和白名单

## 配置要求

- 系统空间安装
- 建议至少 512MB 可用内存
- 需要网络连接以获取最新的威胁情报
